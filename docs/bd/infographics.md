# Image generation record

The assets were generated independently in text-to-image mode, then resampled to 1920 by 1080 and
visually inspected.

## Protected-debt hero

Prompt intent: a protected geometric debt core inside layered dark-blue and purple structure, ample
negative space, no copy or logos.

## Continuous lifecycle

Prompt intent: many small positions entering a shared fixed-expiry facility, a liquid reserve layer,
optional unused-capacity vault and default or healthy terminal paths. This replaced an earlier image
which incorrectly showed an arbitrary funding window. The final contract uses a market-specific entry
cutoff derived from the credit-event horizon.

## Settlement fork

Prompt intent: one bundled position resolving into default cash plus debt recovery, or healthy
collateral return plus holder debt redemption. Carmine is restricted to the default branch.
